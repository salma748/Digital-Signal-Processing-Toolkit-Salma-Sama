
# Digital Signal Processing Toolkit — Salma & Sama

A Python-based Digital Signal Processing (DSP) project developed collaboratively by Salma and Sama.

## Overview

This project provides a graphical interface for working with digital signals and exploring digital signal processing concepts.

## Features

- Graphical user interface for interacting with signals
- Signal visualization and plotting
- Signal processing operations
- Modular project structure

## Technologies Used

- Python
- Tkinter
- Matplotlib

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/DSP-Toolkit-Salma-and-Sama.git
cd DSP-Toolkit-Salma-and-Sama
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment on Windows

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Run the application

```bash
python main.py
```
